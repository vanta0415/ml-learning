ml-learning 暑期练习

这个仓库按周放作业。前两周是图像处理，从第3周开始是深度学习。

目录说明
1. image_processing/   第1-2周 OpenCV 代码和结果图
2. deep_learning/      第3周及以后的 PyTorch 代码和结果图
3. notes/              每周笔记
4. requirements.txt    用到的库

第1周 图像基础
- 代码：image_processing/week01_image_io.py
- 原图：image_processing/data/flower1~3.png
- 结果：image_processing/output_week01/
- 笔记：notes/week01.md
- 内容：读图、灰度、HSV、缩放

第2周 增强边缘和计数实验
- 代码：image_processing/week02_cv_demo.py
- 结果：image_processing/output_week02/
- 笔记：notes/week02.md
- 内容：增强、Canny、形态学、硬币轮廓计数

第3周 深度学习训练入门
- 代码：deep_learning/week03_dl_basics.py
- 结果：deep_learning/output_week03/
- 笔记：notes/week03.md
- 内容：线性回归、对比学习率、loss曲线

怎么看
- 想看某周：先打开对应代码，再看 notes 和 output 结果图
- 第1-2周在 image_processing，第3周在 deep_learning，不是漏了，是按内容分的文件夹
